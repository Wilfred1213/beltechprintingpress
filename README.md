# Beltech Printing Press Management System 🖨️

Beltech Printing Press is a professional web application built with Django, designed to manage printing service categories, blog updates, and newsletter subscriptions.

## 🚀 Features
* **Dynamic Service Management:** Showcase printing categories (Invitation cards, Flyers, ICT, etc.).
* **Newsletter System:** Integrated with Zoho Mail for official communication.
* **Secure Staff Portal:** Hidden authentication path to protect against unauthorized access.
* **Responsive UI:** Styled with Font Awesome 6 and custom CSS.
* **Production Ready:** Configured for deployment on PythonAnywhere.

## 🛠️ Tech Stack
* **Backend:** Python 3.10+, Django 4.2+
* **Database:** SQLite (Development/Production)
* **Email Service:** Zoho Mail SMTP
* **Deployment:** PythonAnywhere
* **Icons:** Font Awesome 6 (Solid/Regular)
